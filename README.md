# Taipei Medical Congress 2026 Notes|2026 台北醫學會演講筆記

> 2026-08-08 台北醫學會(北醫附醫 50 週年院慶研討會)四場演講的個人筆記網站:健康政策、AI 精準醫療、全球健康創新,外加逐項附來源連結的事實查證。

筆者當天在臺北醫學大學現場聽了四場演講(衛福部林靜儀次長、國衛院許惠恒副院長、Vanderbilt 石瑜教授、Stanford Biodesign 的 Anurag Mairal 教授),會後把筆記整理成這個雙語網站;演講中可查證的事實均逐項比對公開來源並附上連結。

## ✨ 功能特色

- 🌏 **雙語切換** — English / 中文一鍵切換,整站重繪
- 🌗 **深色 / 淺色模式** — 一鍵切換並記憶偏好
- 📄 **每場演講獨立頁面** — 附目錄與閱讀進度條,可單獨分享
- 🕘 **議程時間軸** — 當天上午實際議程一目瞭然
- ✅ **事實查證表** — 可排序、搜尋,依場次與判定篩選,每項附來源連結
- 📱 **響應式設計** — 手機、平板、桌機皆適配
- ⚡ **純靜態** — 無後端、零建置、載入快
